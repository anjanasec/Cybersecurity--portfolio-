
# Wireshark DNS Traffic Analysis

## 1. Project Overview
Hands-on network traffic analysis using Wireshark on macOS to understand DNS queries, responses, and local network communication.

## 2. Objective
- Understand how DNS works.
- Identify DNS queries and responses.
- Examine source and destination IP addresses.
- Understand DNS port 53.
- Explore local network discovery using mDNS.

## 3. Lab Environment
- Operating System: macOS Big Sur
- Device: MacBook Air (Intel)
- Tool: Wireshark 4.4.19
- Network: Home Wi-Fi

## 4. Practical Exercises

### Exercise 1: Capture Network Traffic
Started a live packet capture on the Wi-Fi interface using Wireshark.

### Exercise 2: Analyse DNS Queries
Used the display filter:

`dns.flags.response == 0`

Observed DNS queries generated by the Mac.

### Exercise 3: Analyse DNS Responses
Used the display filter:

`dns.flags.response == 1`

Observed DNS responses from the local DNS resolver.

### Exercise 4: Identify Network Communication
Observed communication between:
- Mac: Local client device
- DNS resolver: Local router
- DNS service port: 53

### Exercise 5: Observe mDNS
Observed local network discovery traffic, including Spotify Connect service discovery.

## 5. Key Findings
- DNS translates domain names into IP addresses.
- DNS commonly uses UDP port 53.
- DNS queries request information.
- DNS responses return answers or errors.
- mDNS supports local network service discovery.

## 6. Skills Practised

- Network protocol identification
- IP address analysis
- Display filters
- Basic network troubleshooting
